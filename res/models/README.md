# Sample models

`human.glb` is "Animated Human" by Quaternius, released under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/), from
https://opengameart.org/content/animated-human-low-poly. It was converted
from the pack's `.blend` by `scripts/convert-human.py`: scaled to 1.8 m,
feet at -0.9, facing -Z, with the light clothed skin, and only the Idle,
Walk, Run, Jump, Punch and Death clips kept.
